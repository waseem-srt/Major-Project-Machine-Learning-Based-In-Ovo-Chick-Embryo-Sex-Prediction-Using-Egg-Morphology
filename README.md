# Major-Project-Machine-Learning-Based-In-Ovo-Chick-Embryo-Sex-Prediction-Using-Egg-Morphology

1. TITLE OF THE PROJECT:

Machine Learning-Based In-Ovo Chick Embryo Sex Prediction Using Egg Morphology

2. AIM / OBJECTIVES OF PROJECT:

To develop a low-cost and non-invasive system for predicting chick embryo sex using external egg morphology, smartphone-based imaging, image processing, and machine learning.

3. SCOPE OF THE PROJECT:

The project focuses on capturing standardized egg images, extracting morphological features such as length, width, area, eccentricity and extent, and using machine learning models to predict embryo sex. The system aims to provide an affordable foundation for non-invasive in-ovo sex prediction.
